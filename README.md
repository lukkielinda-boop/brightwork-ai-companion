# Brightwork Ai Companion

Start building the AI Productivity Assistant with the unified dashboard and six productivity tools based on the attached specification:
1. Smart Email Generator
2. Meeting Notes Summarizer
3. AI Task Planner and Scheduler
4. AI Writing Assistant
5. Document/Report Drafter
6. Brainstorming Assistant

Include the unified dashboard, collapsible sidebar navigation, Recent Activity, Settings, Help & Documentation, prominent Responsible AI disclaimer, copy/export controls, and clear error/empty states.
